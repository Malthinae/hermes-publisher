Hermes

A personal desktop application for publishing short-form vertical video.

Hermes writes a script, renders the video locally at 1080×1920 with synthetic voice-over and burned-in captions, and uploads the finished file to its operator's own TikTok and YouTube channels through those platforms' official publishing APIs.

What it does

  • Researches topics and drafts a script.
  • Renders a vertical video on the operator's computer — no cloud rendering.
  • Uploads through the official TikTok Content Posting API and the YouTube Data API v3.
  • Records publish results so failed uploads can be retried.

Who it is for

One person: the owner of the computer it runs on and of the channels it publishes to. There is no public sign-up, no third-party users, and no data collected from anyone else.
